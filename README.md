# 📊 Data Science – IBM Cloud & Watson Studio

## 📌 Overview

This repository contains a Data Science practical assignment based on **IBM Cloud, Watson Studio, and Jupyter Notebook**.

The practical demonstrates how to access IBM Cloud, open Watson Studio, create a Data Science project, and add and launch a Jupyter Notebook for data science tasks.

## 🎯 Objective

The main objective of this practical is to understand:

- How to access IBM Cloud
- How to access Watson Studio
- How to create a new project
- How to manage project assets
- How to add a Jupyter Notebook
- How to launch and use the Jupyter Notebook environment

## 🛠️ Tools & Technologies Used

- ☁️ IBM Cloud
- 🤖 Watson Studio / watsonx
- 📓 Jupyter Notebook
- 🌐 Google Chrome / Microsoft Edge
- 📝 Microsoft Word

## 📝 Practical Question

**How can IBM Cloud and Watson Studio be used to create and run a Jupyter Notebook for data science tasks?**

## 🔄 Steps Performed

### 1. IBM Cloud Website Login
Opened the IBM Cloud login page and accessed the platform using valid credentials.

### 2. IBM Cloud Dashboard
Accessed the IBM Cloud dashboard and explored the available cloud services and resources.

### 3. Accessing Watson Studio
Opened the navigation menu and accessed Watson Studio through the IBM Cloud platform.

### 4. Watson Studio Home Page
Opened Watson Studio and accessed its data science and machine learning tools.

### 5. Creating a New Project
Created a new project by providing the required project and storage details.

### 6. Project Dashboard
Opened the project dashboard and accessed the **Assets** section for managing project resources.

### 7. Adding a Jupyter Notebook
Searched for and selected the **Jupyter Notebook editor** to add a notebook to the project.

### 8. Jupyter Notebook Interface
Provided the required notebook details, selected the runtime, and created the Jupyter Notebook.
